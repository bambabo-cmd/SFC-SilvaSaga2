## 적용 방법

1. 압축을 푼 무수정 원본의 크기·MD5·CRC32 또는 SHA-256이 위 표와 일치하는지 확인합니다.
2. 아래 해당 패치를 원본에 **한 번만** 적용하고 결과를 별도 파일로 저장합니다.
3. 적용 후 결과 크기와 체크섬을 다음 표와 대조합니다.

위 원본에는 512바이트 외부 복사기 헤더가 없습니다. `.smc`/`.sfc` 확장자만으로 헤더 여부를 판단하지 말고 파일 크기·해시를 확인하세요.

xdelta3 사용 예시(모든 경로는 큰따옴표로 묶습니다):

```text
xdelta3 -d -s "Silva Saga II - The Legend of Light and Darkness (Japan).sfc" "Silva Saga II (Korean) WIP348.xdelta" "Silva Saga II (Korean) WIP348.sfc"
```
